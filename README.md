### About Me

I'm a **Software Engineer**, **Full-Stack Developer**, and **AR/VR enthusiast** based in Mumbai, India.  
Currently pursuing a **B.Tech in Computer Science & Engineering** at K.J. Somaiya College of Engineering.

- Currently exploring advanced immersive experiences with **VisionOS** and **Unreal Engine** while architecting scalable web applications and software solutions.
- Led cross-functional teams delivering AR/VR educational simulations, industrial archviz, marine robotics solutions, and enterprise web platforms.
- Passionate about building robust backend systems, responsive front-end interfaces, and seamless user experiences.
- Fun fact: I helped simulate walking on a 250-story plank to alleviate height phobia!
